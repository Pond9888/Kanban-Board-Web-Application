# Fiverr Portfolio Recording Guide

## Screenshots (for Fiverr gig images)

### Setup
- Open browser at **1280×720 resolution** (or set zoom so content fits)
- Go to: https://kanban-board-web-application.vercel.app

### Slide 1 — Thumbnail (thumbnail.html)
Open `thumbnail.html` in browser → Full screen → Screenshot

### Slide 2 — Features (slide2-features.html)
Open `slide2-features.html` in browser → Full screen → Screenshot

### Slide 3 — Packages (slide3-packages.html)
Open `slide3-packages.html` in browser → Full screen → Screenshot

### Slide 4 — Live App Screenshot
1. Go to `/board` page
2. Open a card modal (click any card)
3. Go to "Agents" tab, run an agent — wait for "Working" status
4. Screenshot the full screen showing the modal + board behind

## MP4 Video (60–90 seconds recommended)

### Tool: OBS Studio (free) or Loom or macOS QuickTime

### Script — Record in this order:

**[0:00 – 0:08] Opening — Dashboard**
- Open https://kanban-board-web-application.vercel.app
- Show the Dashboard with stats cards
- Hover over stat cards slowly

**[0:08 – 0:20] Kanban Board**
- Click "Kanban Board" in sidebar
- Slowly scroll to show all 4 columns and cards
- Drag one card from "Todo" to "In Progress" (drag-and-drop)

**[0:20 – 0:40] AI Agents Demo**
- Click on any card to open the modal
- Go to "Agents" tab
- Select "Researcher" from the dropdown
- Click "Run Agent"
- Watch the status go: Thinking → Working → Done
- Show the AI result output

**[0:40 – 0:55] AI Chat**
- In the same modal, click "Chat" tab
- Type: "What are the main steps for this task?"
- Show the streaming response appear word by word

**[0:55 – 1:05] AI Summarize + Priority**
- In the same modal, go to "Details" tab
- Click "✨ AI Rewrite" button — show description update
- Click "🎯 Suggest Priority" — show priority suggestion popup

**[1:05 – 1:20] Other Pages**
- Click "My Tasks" in sidebar
- Click "AI Agents" in sidebar
- Click "Analytics" in sidebar
- Quick 3-second view of each

**[1:20 – 1:30] Closing**
- Go back to Dashboard
- Fade out / end recording

## Video Editing Tips (CapCut / DaVinci Resolve / iMovie)

1. Add text overlays at key moments:
   - "AI Agents Running in Real-Time" when showing agent status
   - "Streaming Chat — No Page Reload" during chat demo
   - "Built with Next.js 14 + Claude AI" at the end

2. Add subtle background music (upbeat, tech-themed) at 20-30% volume

3. Add a short 2-second intro title card:
   - "AI-Powered Kanban Board"
   - "Built by [Your Name] on Fiverr"

4. Export settings:
   - Resolution: 1920×1080
   - Format: MP4 (H.264)
   - Framerate: 30fps or 60fps
